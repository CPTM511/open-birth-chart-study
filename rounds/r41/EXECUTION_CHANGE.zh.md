# R41 执行补记 · 复用紫微相同输入的年度结果

初始运行继续调用未修改的 R10 全流程。确认在同一台 Linux 计算机中，紫微年度子程序占用大部分计算时间。按冻结的紫微程序，生日、时辰指数、F/M 参数、年度列表、引擎配置及调用方式相同时，年度结果完全确定。程序原本已经按前三项复用命盘。整数分钟处于相同本地日期和时辰指数时，日历年列表及上述其他条件也相同。

在工作副本增加仅限本轮标准输入的紫微复用包装。仍用 R10 对每个不同键首次实际评分。对相同键复用结果时，把原记录的时刻标签和身份字段恢复。八字、七政四余及西方占星仍逐个分钟调用原评分。样本、各体系算式、阈值、主比较、权重和终点保持原登记。

启用前，以两个年份各自第一组固定日期完整比较原入口与复用入口。共 5,760 个标准输入、921,600 项四体系年度分数，必须逐值相同。另保留原登记的 672 个用未复用流程作的新运行样例，覆盖全部日期。新路径如有差异，就保留原算法执行并诊断。改动是为缩短等待，在查看新的区间、变动率或跨组差异之前登记。记录原入口和复用入口的产物及签名。
