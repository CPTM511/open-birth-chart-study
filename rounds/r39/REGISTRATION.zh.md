# R39 研究登记 · 《子平真诠》月令用神变化

〈论用神变化〉中，哪些月令、透干及三合条件能按文字重复计算？当变化与保留本格的条件同时满足，章内是否给出可普遍执行的裁决？核对世界图书馆本与合刊第二卷。登记前已目读两印本，知悉若干异文以及同一日月条件可能重叠。尚未运行本轮判据、四柱枚举、反例或 R8 规则对照。

两版均收录开篇寅月甲主、甲不透而丙透的说明，未定日干，单独核对藏干与透干的陈述。其余按原书顺序登记。世界图书馆本有十二个日月条目，合刊有十三个。页码、字面条件和版本差异冻结在[判据表](cases.json)。

| 章内例 | 检验的条件 |
| --- | --- |
| 丁亥与己申两条总例 | 丁亥逢卯未成三合木，原文称化印。己申藏庚、透壬，原文称化财。 |
| 辛寅化官 | 逢丙。按前段文义读为非日干透丙，甲是否透出另由保持财格条核对。 |
| 壬戌化印 | 合刊逢辛，煞转为印。世界图书馆本另作伤转财且未列相应触发字，核月支所藏的角色，保留触发条件及条目组合数空缺。 |
| 癸寅化财 | 合刊有此条，藏甲、透丙，午戌与寅齐。原文续论「透官」，另外统计由日干推得的正官戊同透。世界图书馆本未陈述这条癸寅前提。 |
| 乙寅月劫变化 | 透戊且午戌与寅齐。合刊称食伤。世界图书馆本印作「月生」，可数前提，不统一结果词。 |
| 丙寅与丙申两条不善 | 丙寅的甲不透，午戌与寅齐。丙申藏庚、透壬，子辰与申齐。 |
| 辛寅与乙申两个兼格 | 辛寅丙甲俱透，财主而官兼。乙申壬戊俱透，另核戊生庚、戊克壬，官主而印兼。 |
| 癸寅还取伤官 | 丙甲俱透，正文称戊官忌见。条文没有把午戌缺席写成前提，单列戊透子集。 |
| 丙寅与丙申两个还取本格 | 丙寅午戌齐，合刊透甲或壬，世界图书馆本列壬。丙申壬戊俱透，另核戊制壬、生庚。正文没有在后例重述子辰齐，交集单列。 |

对每个日干与月支，穷举合法四柱的六十甲子组合。由年干起月和日干起时生成，与先枚举候选再检查两条起干关系的方法对账。每个日干与月支理论上各有 3,600 种，分母是干支组合，未赋予时长或出生频数。只计年、月、时的天干为透干。「或」按包含式处理，取两项并集。三合只核原局与月支同组的三支是否齐备。主读法中「藏甲／庚」核月支所藏，允许同字在别柱透出。敏感性读法仅对「藏某透某」的三处另要求前者不透。「甲不透」在两套规则都必须满足。每版分别公开各条匹配数与辛寅、癸寅、丙寅、丙申四对变化／保留条件的交集，癸寅交集再列戊透分层。保留所有计数、零值、缺句和无法执行的异文。两版合并后不作统计划分或择一取胜。

独立以五行差和阴阳同异查十神，再与现有十神表对照。独立以十二支同余分组查三合，再与现有三合表对照。检查书中明示的生克方向。分别统计固定的 R8 月令选择器在各条下给出的候选、竞争和三合留待裁决状态，不在此轮修改原选择器或任何分数。章内针对某例的保留与兼格可以识别，跨例的统一优先级只有在可排除冲突读法时才视为已裁决。

按同一日干与月支构造七对反例或切换例。固定表列其余前提，改变以下条件。

| 对照 | 固定条件与改变项 |
| --- | --- |
| 丁亥三合木 | 未支和透干集合固定，改变有无卯支。 |
| 己申藏庚 | 庚不透，壬和癸互换，固定其余可见干集合。 |
| 辛寅兼格 | 丙恒透，改变有无甲。 |
| 癸寅伤财并列 | 甲丙恒透并保持同一非日干集合，改变三合火的完备性。戊是否也透另作分层。 |
| 丙寅透壬 | 三合火齐、甲不透，改变有无壬。 |
| 丙寅透甲 | 三合火齐、壬不透，改变有无甲。 |
| 丙申食神 | 三合水齐、壬透且庚不透，改变有无戊。 |

先核是否有成对的合法干支，再尝试为各对生成可通过日历回代的合成时刻。按四柱字序每侧最多尝试 120 组，收集至 12 组可回代的四柱为止。同侧取 1900–2019 年（含）范围内最早可回代的固定 UTC+08:00 公历时刻，取同时满足固定条件、改变柱数最少的一对，同数时按四柱字序选。逆算与正常入口使用同一版本的历法库，结果仅作为合成例的入口校验。若有一侧缺失或预算内无法回代或配对，公布该项及尝试范围，与结构枚举分别处理。

两版影印文件分别取得两份，匹配先前登记的散列。登记推送后运行判据。两套枚举须一致，机器结果须二次运行一致。记录原文缺句、软件刻意保留的未裁决内容，以及读法影响，不借本轮推断个体结果或人口出生率。
