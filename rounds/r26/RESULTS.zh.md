# R26 · 出生星期与时段的权重敏感性

以 R10 的七组和 R12 的墨西哥 2023 年留出组为样本，复核 **16,000 条出生记录**、640,000 个建模记录年。保留巴西 2006 年原阈值、各条记录的原时地和四体系输出。在每个出生季度和性别层内，让周一至周五与周末、09:00–17:59 与其他小时的联合权重等于两个边际相乘所得权重。**七组目标对比的最大移动为 0.014 个百分点，七项同时 95% 近似区间均完全落在预设的 ±0.10 个百分点内。** 本次粗分辨率的星期与时段变权，移动幅度远小于 R10 已见的几项上移。[登记](REGISTRATION.zh.md) · [R10 参照](../../R10.md) · [R12 留出](../../R12.md) · [逐组结果](results.json)

| 出生组 | 原差值 | 调整后差值 | 对比移动 | 对比移动的同时 95% 近似区间 |
| --- | ---: | ---: | ---: | ---: |
| 巴西 2007 | +0.1550 | +0.1545 | −0.0005 | −0.0239 至 +0.0229 |
| 巴西 2010 | −0.0571 | −0.0507 | +0.0065 | −0.0195 至 +0.0324 |
| 巴西 2020 | +0.6154 | +0.6211 | +0.0058 | −0.0204 至 +0.0319 |
| 巴西 2024 | +0.5138 | +0.5002 | **−0.0136** | −0.0415 至 +0.0142 |
| 墨西哥 2009 | −0.1919 | −0.1901 | +0.0019 | −0.0190 至 +0.0227 |
| 墨西哥 2020 | +0.3994 | +0.4034 | +0.0040 | −0.0166 至 +0.0246 |
| 墨西哥 2023 | +0.0002 | +0.0054 | +0.0053 | −0.0117 至 +0.0222 |

表内单位为百分点。原差值使用巴西 2006 年固定联合高分率 **3.214943%**。调整后差值同时对目标和巴西 2006 分别按相同规则变权，再作组间比较。所有高分标记采用原阈值。这一诊断中巴西 2006 单独随变权移动 −0.0031 个百分点。每条出生记录的贡献是 20–59 岁四十个建模年份中至少三体系高分的比例。区间利用原采样层里整条记录之间的变化、一阶近似、有限总体校正和两个出生组的独立抽样近似，七项使用 Bonferroni 同时范围。[方法和结果](clock_balance.py)

按出生月和性别分层时，七个对比的最大绝对移动为 **0.0334 个百分点**。主口径的最小联合格为 14 条记录，调整后的有效样本量为每组 1,989–1,998。主口径造成的州组成总变差最高为 0.32 个百分点。按月口径最小一格有 1 条记录，故作为描述性敏感性结果。独立以有理数从原权重逐条重算，两种口径保留的加权星期和时段边际逐项相等。[核对脚本](verify_points.py) · [核对收据](review.json)

R25 的日本资料说明同一星期几的法定节日仍可有明显的出生时段差。R26 只处理工作日／周末与两类时段的分布，并未把日本的出生时间分布套到其他国家。每个来源的实际节日、精确分钟及州内登记差异仍可能产生不同影响。R11 之前按共同历年和季节等条件重排各体系的结果，与这次对同一记录的四个体系一起变权回答的是不同研究问题。R12 的墨西哥 2023 年留出继续接近固定参照，真实结局及独立第三地队列仍缺少相应验证。[R25](../../R25.md) · [R11](../../R11.md) · [项目证据进展](../../RESEARCH_STATUS.zh.md)

## 复算

原出生时地、抽样记录和分数仅在授权范围内保管。复算读取由 R10、R12 的源材料和验收收据重建的工作目录。程序先核对相应散列，再复现两个轮次公布的原率，然后进行本轮变权。

```sh
python -m rounds.r26.clock_balance --r10-job "$R10_PRIVATE_JOB" --r12-job "$R12_PRIVATE_JOB" --output "$NEW_RESULTS"
cmp rounds/r26/results.json "$NEW_RESULTS"
python -m rounds.r26.verify_points --r10-job "$R10_PRIVATE_JOB" --r12-job "$R12_PRIVATE_JOB"
python -m unittest discover -s tests -p 'test_r26_*.py'
```
