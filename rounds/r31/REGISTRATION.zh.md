# R31 研究登记 · 《子平真诠》相神条文与救应受损

两印本的〈论相神紧要〉如何区分候选救应与承担救应的相神受损？本轮核对全章七个展开的结构例，以及开篇未指定干支的三个角色示例。以国图藏世界图书馆本 PDF 39–41 页（印页三十至三十二）及国图藏合刊第二卷 PDF 32–33 页（印页十九至二十）为证据。登记前已读两影印本，知道版本差异和一次年月干支冲突的可能性。尚未运行本轮判据、组合枚举或反例。

| 章内例 | 预先规定的可检验结构 |
| --- | --- |
| 甲日酉官，丁与壬 | 月支辛为正官。丁克辛，壬与丁五合，按本章局部读法制约伤官。 |
| 戊日子财，甲与己 | 月支癸为正财。甲克戊，己与甲五合，按本章局部读法制约七杀。 |
| 乙日酉杀，年丁、月癸、时戊 | 月支辛为七杀，癸克丁，丁克辛，戊与癸五合。另以年干丁、月支酉和月干癸的字面读法核五虎遁。角色示意与合法年月组合分别处理。 |
| 癸日亥月，丙与卯未 | 亥本气壬为劫财，丙为正财。卯、未与亥构成三合木的支字前提。木为癸所生，并能生丙火。只核支字条件。 |
| 庚日与子辰 | 世界图书馆本为甲月、透水，合刊为申月、透癸。分别核月支能否解析、三合水支字、透干与藏干同字及同五行两种通根读法。不以合刊改写底本。 |
| 甲日酉官，丁、癸再逢戊 | 癸克丁可制约丁克辛；增加戊癸五合时，癸保护官星的作用按本章局部读法失效。 |
| 丁日酉财，癸、己再逢甲 | 己克癸能制约癸克丁，己也可生月支财。增加甲己五合时，食神制杀按本章局部读法失效。 |

逐例核十神和五行方向。对五个五合例给出有、无所述合干的对照。对两个三合例各删除指定会合支，核对候选条件消失。以六十甲子、年起月干和日起时干的两套算式枚举每版结构能够容纳的四柱组合数；保留原书没有指定的柱位，不对任何具体人物补造四柱。不把合法干支组合视作已按真实出生日期校验。日支未指定，不引入实际历日限制。

每例区分印本用字、可计算的结构前提、字面组合是否成立及仍待裁决的合化／先后／旺衰。开篇的财旺生官两印本分别记录用与相的角色。章内对同类干支的文字差异逐条说明。相神受损的判断限制于表中指定关系，通用格局裁决仍需独立证据。登记推送后运行判据。两印本逐页复核、两套枚举结果及反例都对账才发布。没有修改冻结评分权重或将本轮条件发回出生队列。
