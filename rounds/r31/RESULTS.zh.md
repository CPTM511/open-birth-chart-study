# 《子平真诠》相神条文复核

两印本七例中的可辨干支、生克、十神与合会前提逐项对照。五个干合例在有、无指定合干时均产生预先登记的局部关系变化。两组三合条件在可解析读法中各删除一个指定支字，共四项，完整三合条件均消失。合绊优先于下一段生克是本轮针对这些段落采用的局部读法，实际旺衰、合化及其他干支竞争仍待裁决。[登记](REGISTRATION.zh.md) · [可重算结果](results.json)

| 原书例 | 可核的作用 | 世界图书馆本／合刊本可容纳的四柱组合 |
| --- | --- | ---: |
| 甲日酉官，丁壬 | 丁伤官可克辛官。壬合丁后，这条克官关系在局部模型中停用。 | 144／144 |
| 戊日子财，甲己 | 甲杀克戊。己合甲后，这条克身关系停用，子中癸财仍是月令前提。 | 144／144 |
| 乙日酉杀，年丁月癸时戊 | 癸印克丁食，戊合癸可令丁恢复制辛。在指定丁年中，酉月由五虎遁起为己酉，不能同时为癸酉。 | 0／0 |

组合枚举同时遵守六十甲子、五虎遁及五鼠遁。逐柱生成后，与从全部候选四柱组合过滤的集合完全相同。组合数只是章内条件在这一干支规则下的取值数，实际历日及人物出生仍待独立证据。第六例的年、月约束可以直接核对。其三种候选年干为丁、癸、戊，对应酉月的月干分别是己、辛、辛，均无法和其余两项同时满足。这样的例子可用于核对原书所讲的关系顺序，字面原局由上述约束限定。

## 复算

在根目录使用项目已固定的 Python 与 lunar-python。从国图影印件的公开镜像分别下载两次。将 `world-library.pdf` 和 `second-edition.pdf` 各存一份到两个不同目录。文件须匹配[登记散列](cases.json)。直接检查上述页图能够核对本轮逐例转录。

```sh
PYTHONPATH=src python -m rounds.r31.replay --source-dir "$R31_A" \
  --second-source-dir "$R31_B" --output "$R31_A/results.json"
```

本轮复用了 R8 的十神、生克和干支会合工具以及 R21 的校验器。另一套枚举用独立的起干查表生成组合。两套共用干支表与同一章例转录。复核属于内部文本和计算检查，结论只涉及这七例的结构条件。
