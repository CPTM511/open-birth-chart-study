# R44 研究登记 · 七杀重逢的本命、流年与救应

核对 R8 紫微附加条款 ZWC03、ZWC04 在何种宫位与星曜条件下和南阳堂明刊《紫微斗数全书》相合。两条古文的现代断句及三方定位须明示。用卷五〈论羊陀迭并〉内的庚生、卯命一例和卷六「孔允夫命」印图作为出处明确的用例。登记前已读两条书文和孔例的网络转录，见到孔例题名及「阴男水二局」、三十二岁、大限寅、太岁申、流羊和七杀重逢等明示文字。尚未从印图转录星位或读出历日，未查询现代引擎或计算枝系比较。[卷五转录](https://www.shidianguji.com/zh/book/SDZJ0170/chapter/1jvzop58rvdbm) · [孔例转录](https://www.shidianguji.com/zh/book/SDZJ0170/chapter/1jvzop8fpmcz7) · [R8 所引三卷通行本](https://zh.wikisource.org/wiki/紫微斗數全書/卷三)

1. 取日本国立公文书馆子060-0001下册全书第 164–166 幅及第 220 幅左图，各取两次全幅，并核相同散列。从印图分别核对具名条文、出生题签、本命命宫、七杀、紫微、天相、禄存、羊陀，以及本例涉及的年龄宫位。字迹、定位或所印字段不足时保留未定。另用南阳堂本卷三〈安大限诀〉〈安小限诀〉和〈安流禄流羊流陀诀〉核起点与行向。[馆方影像清单](https://www.digital.archives.go.jp/api/iiif/4469314/manifest.json) · [卷三转录](https://www.shidianguji.com/zh/book/SDZJ0170/chapter/1jvzooy7dkbhh)
2. 独立计算庚年流羊、流陀及是否与同类本命星重叠，逐个报告照到卯命的星；另举把流年干推进一步的对照。同一盘的七杀守照与羊陀冲照，比较记录「三合」为同宫及 ±4、「三方四正」再加入对冲 ±6，分别对照流羊／流陀出现其一或两者的读法。命宫和七杀所在是两种待比较的救应参照。对具名紫微、天相、禄存，分别保留同宫、三合两翼和对冲位置，报告可见其一及三者齐会。严格入庙与 R8 的庙旺并列，众吉的阈值留空。
3. 按原印孔例用三十二虚岁复核大限和太岁。小限如有可辨宫格则另核。印图的有据推回仅报告为候选。若完整输入可辨，按 R23 的 1924 与 1984 起同一干支载体，走正常 R8 详版入口。若出生月日或时缺失，以印图星位和盘面与年龄关系直接比较；可以用合成载体检验同一改动的引擎响应，载体不充当孔例出生资料。将原书把哪一个条件称为重逢与古算、现代实现分开记录。
4. 对十二宫的全部锚点和星位核三合与四正两个集合，用十二支固定表另行复算。用固定 R8 排盘在同一输入上核验报告的结构条款，合成正反例仅验证条件。没有唯一文证时并列读法，任何提及吉凶、寿夭或诗诀均只用作原典分类，不接入项目既有四体系联合分数，也不读入任何现实结局。

结项条件是两次原件可查、古例所见及其缺失有记录、两种几何写法一致、现代条文逐项可定位。复算结论限于所取的两个文本例和明确列出的假设。
