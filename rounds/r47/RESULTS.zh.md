# 日本日期与小时资料的识别界限

沿用 R41 中 1999、2006 两年各 24 日的日期×小时计数。两面板共有 **148,030 次真实登记出生**有当地日期和小时，同时有 **138,240 项合成输入**的四体系高分年龄掩码可供分配。固定东京坐标及模型年龄 20–59，分钟允许 00–59，两种登记性别输入可选。用 R45 第 80 百分位和逐记录、同龄参照中心化定义十年缺段，最低关注量级为 +5 个百分点。[登记](REGISTRATION.zh.md) · [R41 样本日期和阈值](../r41/REPRODUCE.md)

| 对齐方式 | 同一计数的一组均匀整数分配所得共同峰 | 可达到的共同峰上界 | 上界所在起点 |
| --- | ---: | ---: | ---: |
| 同足岁 | +2.171 个百分点 | +40.170 个百分点 | 50 岁 |
| 同公历 | +2.795 个百分点 | +37.003 个百分点 | 2049 年 |

两种分配都逐小时保留官方人数。上界的构造让每个日期小时单元的出生数全部落在使选定缺段窗口效应最大的选项。对于两个面板共同峰，再在所有起点取「两个面板上界较小值」的最大值。发布的逐单元选择可达此值。均匀构造按选项顺序分配整数，人数与上界构造相同。因两种可行分配分别位于 +5 门槛两侧，确知官方的日与小时合计仍不足以判断是否达门槛。表中的上界是允许分配范围内的数学端点，实际出生的分钟、性别及地点联结未观测。[精确分数及赋值凭据](results.json)

**探索性假设。** 将每个日期小时单元人为按两种性别对半分配，奇数时 F 参数多一条，只保留分钟自由度。同龄峰的均匀构造和上界为 +2.296、+30.239，公历为 +2.812、+27.005 个百分点。这个人工约束下仍同时存在门槛两侧的方案。[附带计算](sex_split_exploratory.json)

重新取回两份官方计数文件，逐日期和小时对照冻结掩码。独立程序按逐位字符和有理数重算全部分组曲线，核查上界见证逐格保留官方计数，并核对均匀分配。所有结论限于这 48 个日期与固定东京坐标。实际出生地和不可见的登记联结继续影响能否在东亚复验四体系结果。[复核](review.json) · [来源资料](SOURCES.zh.md)

## 复算

在完整检出的仓库中使用 R10 的固定参照重建目录，运行以下命令。无需取得任何日本个体出生记录。

~~~sh
python -m rounds.r34.source "$FIRST_JAPAN_SOURCE"
python -m rounds.r34.source "$SECOND_JAPAN_SOURCE"
python -m rounds.r47.bounds --source "$FIRST_JAPAN_SOURCE" --r10-job "$R10_RUN" \
  --output "$R47_RUN/results.json" --sex-split-output "$R47_RUN/sex_split_exploratory.json"
python -m rounds.r47.verify --source "$SECOND_JAPAN_SOURCE" \
  --results "$R47_RUN/results.json" --output "$R47_RUN/review.json"
~~~
