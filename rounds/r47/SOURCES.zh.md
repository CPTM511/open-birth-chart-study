# 东亚同时代出生资料的字段与权限核对

筛查对象为实际 1990–2009 年出生且可核对公历年月日、出生时分、登记性别和发生地的记录。发生地可在证据充分时按发生医院或市镇参考点计入。优先核对原始出版物的样本年代、变量字典和开放方式。聚合、疑似有字段但未获授权以及不符目标年代分别列示。

| 路径 | 原来源确认的内容 | 当前可用范围 |
| --- | --- | --- |
| 日本 e-Stat 1990–2009 受控出生票与公开出生表 | 受控字典可联结日期、小时和性别。公开表有日与小时总数 | 受控字典未列分钟与可定位发生地。公开计数进入 R47 的精确界限。[官方公开表](https://www.e-stat.go.jp/stat-search/database?statdisp_id=0003411915) · [逐年字段核对](../../R36.md) |
| 日本产科妇人科学会围产登记 | 学会报告证实 2001–2009 年已有临床二次使用。金泽大学官方同意说明列分娩日期时间与性别，并明确二次研究经伦理和学会审核 | 历史年份的实际分钟粒度、供研究版发生医院标识以及适用授权仍须审核，没有开放逐条档。[学会历史报告](https://www.jsog.or.jp/activity/pdf/shusanki_vol63no6.pdf) · [二次研究说明](https://web.hosp.kanazawa-u.ac.jp/other/doc/sankafujinka_20250325.pdf) |
| 韩国 MDIS 历史出生微数据 | 官方公告证实 1998–2002 年两种公开版可下载，其差异之一为地址尺度。数据类型和登记年已核到 | 历史公告未证明该时期可用版本联结出生分钟与实际发生地。现行所核字典缺时分，2024 年后出生通报属于后续制度。[历史发布公告](https://mdis.mods.go.kr/bbs/boardDetail.do?boardId=BBSMSTR_000000000003&curMenuNo=UI_POR_P1027&postId=BI_00000000000087826) · [现行字段审计](../../R40.md) |
| 台湾出生通报和 2005 出生世代 | 已核 Health09、Health48 官方历史字典。两路径分别只有出生年月或无释出的月日 | 现有字典无法还原日与分钟联合输入。[受控资料核对](../../R36.md) · [2005 世代核对](../../R38.md) |
| 香港「Children of 1997」 | 出生队列初始 8,327 人，论文有出生日期和性别关联证据。原作者的资料声明指向数据委员会申请 | 已公开的论文与附表没有同条分钟和实际发生医院的研究字段。逐条数据适用委员会许可。[原队列](https://aprmay97.sph.hku.hk/?lang=en) · [资料声明](https://pmc.ncbi.nlm.nih.gov/articles/PMC5688155/) · [字段用途](https://pmc.ncbi.nlm.nih.gov/articles/PMC8220454/) |
| 中国大陆广州围产保健与分娩监测 2001–2015 | 原研究见到超过 230 万出生记录、出生日期和性别。数据可经数据管理方许可提供 | 本次可核的研究字段未证实出生时分，研究版受许可限制。[原研究资料声明](https://pmc.ncbi.nlm.nih.gov/articles/PMC5430650/) |
| 中国大陆武汉电子分娩登记 | HEI 的实际用档覆盖 2010–2013 年，附录 H 列出生小时、分钟和性别。另有 2001–2012 年发布的年度出生计数 | 核到分钟的研究期晚于目标年代。早期年度汇总无法证明当时可用微数据保留相同字段。[HEI 原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC7266370/) · [字段字典](https://www.healtheffects.org/system/files/Qian189-AdditionalMaterials.pdf) · [早期聚合表](https://datasetcatalog.nlm.nih.gov/dataset?q=0000500756) |
| 中国大陆出生医学证明 | 官方版次记录第一版自 1996 年启用。第七版公开样证有出生时分、性别、发生地及医疗机构字段 | 公开版本制度与样证不能证明 1990、2000 年代日、时、地在可授权研究版中同时保留。[版次公告](https://wjw.hunan.gov.cn/wjw/zxts/cjwt/202210/t20221011_29050552.html) · [官方证明式样](https://www.shqp.gov.cn/shqp/shqp/upload/202304/0416_155919_142.pdf) |

所核来源中还没有能直接评分的同期东亚逐条记录。R47 的正式结果来自四体系合成网格与已核真实聚合计数。授权和历史输出字段仍是扩展到实际样本的必要证据。
