# R9: empirical AI observables

This track starts a separate evidence base for task automation, employment displacement, and loss of human control. Birth-chart results do not enter any AI-risk calculation. This release contains actual public-source downloads and a descriptive data audit; it does not estimate a causal employment effect or an extinction probability.

## Completed acquisition

Seventeen public endpoints returned HTTP 200. Sixteen snapshots are complete. The large ILOSTAT catalogue was capped at 8 MB; its hash identifies a prefix, explicitly marked incomplete. The indicator directory, selected data file, and required dictionaries were downloaded completely. Retrieval timestamps, byte counts, URLs, and SHA-256 values are in [source_fetch_manifest.json](source_fetch_manifest.json). Raw HTML and source archives stay outside this repository.

## Actual labor extract and its limitations

[The published CSV](metrics/labor_lfs_isco08_major_total_sex_2020plus.csv) retains 5,211 aggregate rows for 121 reference areas and 122 area/source pairs: 2020 onward, labour-force-survey sources, both sexes, and ISCO-08 one-digit groups 0–9. Original values and notes are preserved; dictionary labels were joined. It contains **340 series-break flags, 24 unreliable flags, and 9 missing numeric values**. These flags have not been repaired or silently dropped. There are no duplicate full series keys in the 2020-onward source extract.

This table has **no age field**, so it cannot test 1990s/2000s birth cohorts or youth entrants. Its occupation groups are broad. Unequal coverage, series breaks, multiple sources, and occupation crosswalks must be resolved before any longitudinal comparison. No AI adoption variable, exposure merge, regression, or causal effect was estimated.

See [labor_audit.json](labor_audit.json), [year coverage](metrics/labor_coverage_by_year.csv), [area coverage](metrics/labor_coverage_by_area.csv), [evidence ledger](evidence_ledger.json), and [operational protocol](operational_protocol.md). METR estimates and their published intervals are in [metr_model_horizons.csv](metrics/metr_model_horizons.csv).

## Reproduce

```bash
python rounds/r9/ai/acquire_sources.py --raw-dir /tmp/obcs-r9-ai
python rounds/r9/ai/build_evidence.py --raw-dir /tmp/obcs-r9-ai --out-dir rounds/r9/ai
```

The build requires the frozen source hashes in this release. If upstream files change, it stops rather than silently reproducing a different snapshot. A new acquisition writes its own manifest in the raw directory; preserve and review changed sources as a new version before updating the frozen manifest. Human-authored claim interpretations in the ledger and protocol are not generated by the parser.
