# R28 研究登记 · 《子平真诠》〈论偏官〉全章命例

检验 R8 的月令选择及 BZC05 条文对这章的覆盖，并用明确的结构前提复核食制、杀印、财解、官杀去留以及刃／印两个印本的不同读法。纳入本章给出完整四柱的全部八例。底本为国图藏世界图书馆发行本 PDF 78–81 页（印页 69–72），对照国图藏《渊海子平／子平真诠》合刊本第二卷 PDF 57–59 页（印页 44–46）。正文自章题至取运章题前。登记时已看过两个影印本并读出四柱与条文，未运行冻结 R8 或本轮判据。两印本用来核对文字，可能沿袭共同底本。[世界图书馆本](https://commons.wikimedia.org/wiki/File:NLC416-11jh010455-35296_子平真詮.pdf) · [合刊本影印](https://upload.wikimedia.org/wikipedia/commons/d/d5/NLC416-13jh002326-46443_%E6%B7%B5%E6%B5%B7%E5%AD%90%E5%B9%B3_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE_%E7%AC%AC2%E5%8D%B7.pdf)

分析单位为一例年、月、日、时四柱。两本对照逐项验六十甲子及五虎遁、五鼠遁。保留书内异文，另列本章所用十神角色和实际柱位。使用冻结 R8 的藏干和阴阳五行口径作结构对照。月令七杀语境指七杀干为月支本气或同一藏干已经透出。以此作本轮部分候选的前提；另列只透七杀或同五行根的情形。藏干的阴阳有区别，辰中癸不可用作壬已经藏在辰中的证据。

| 原书命例与命题 | 预先规定的可检验结构 |
| --- | --- |
| 1　食制 | 月令七杀，食神透出，财印皆未透。身、杀与食的强弱需独立裁决。 |
| 2　财先食后、甲印调食 | 记录透出七杀与食神、透甲印及戊在四支的位置。另查可见的财是否早于食、辰中是否藏同一壬干。两项不合时将这一列记为部分可核，保留财序、辰藏干口径和强弱的未决问题。 |
| 3　杀印同通月令 | 以同一月支藏干中的两支实证核对已透的七杀与印。 |
| 4　财去印而留食 | 查透财克透印、透印克同一透食伤、该透食伤克月令七杀的三段五行方向。明列此例用伤官为广义食伤，平行检查只认食神时的结果。 |
| 5　煞化印而用财 | 查亥月七杀、寅亥相合、木印与财皆透的候选前提。合化是否成立待裁。 |
| 6　去官留杀 | 查可见的相邻伤官克正官、月令七杀仍见于藏干的候选前提。官是否已去待裁。 |
| 7　去杀留官 | 查月支七杀与载有正官透干的柱支相冲。杀是否被去待裁。 |
| 8　用刃或用印 | 查月令七杀、不见食伤、阳日干见帝旺支，另列支中印；底本正文读刃，合刊本同句读印，合刊本〈论偏官取运〉仍读刃。两种证据均保留，版本分歧未裁。 |

每例无论是否复现均发布，原书结论与结构判据分别保留。R8 统计七杀月令候选、唯一候选及 BZC05a–c 命中的案例数。只有明确可计算的结构计入本轮核对，专门列出部分可核及未裁决的前提。另造合法四柱，逐一移除月令杀、财印链中的透财、六合、去官的伤官、去杀的相冲、阳刃、共同月支根及无透食条件，检查对应提示消失。公开来源页码、对照清单、版本和可重算结果。不使用生平、现实结局或队列评分。先将登记及八例推送 GitHub，再运行结构判据与 R8 对照。[研究宪章](../../CONSTITUTION.zh.md) · [R21 正官章](../../R21.md)
