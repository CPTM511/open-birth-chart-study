# R11 研究登记 · 四体系联合高分的历法对照

**OBS-R11-CALENDAR-2026-11-27 · 2026 年 11 月 27 日 · 宪章 v1.0。** 本轮承接原规划中检验历法共同结构的一项工作。R10 已知结果是巴西 2020、巴西 2024 和墨西哥 2020 相对巴西 2006 的联合高分比例抬升。现在问一个可以反查的问题。保留同一出生队列的成人历年、出生季节、出生州及性别，并按这些条件重新配对四体系的轨迹，可以重现这些差值的多少？如果重排基线的差值接近观测差值，原差异可在保留的结构下重现。若差值仍有明显剩余，共享这些条件下的分数边际不足以重现全部差异。

已看过公开的 R8–R10 汇总和本轮所需的出生字段配对人数。本登记冻结时尚未计算 R11 的重排均值、差值或检验。使用已经分析过的纪录，是对 R10 的回顾性机制诊断。新的国家或整出生年份留出验证需要独立立项。[研究宪章](../../CONSTITUTION.zh.md) · [R10 结项](../../R10.md) · [机器可读登记](protocol.json)

## 输入和分母

保留巴西 2006 固定参照和 R10 全部六组目标，巴西 2007、2010、2020、2024，墨西哥 2009、2020。每组 2,000 条，合计 14,000 条受限出生登记、560,000 个建模记录年。选用同一批已封存轨迹、州×性别设计权重和 20–59 岁窗口。继续按巴西 2006 同十岁段的加权中间分布分位判定单体系达到第 80 百分位。每个记录年至少三个体系合格即计入联合高分。墨西哥两份原始抽样说明仍缺失，运行沿用 R10 独立恢复并经核验的设计。复核七组原联合比例须与已发布 R10 一致。第七个 R10 目标国家仍缺合格输入，对其没有新的估计。[评分与恢复](../r10/independent_replay/RESULTS.zh.md)

## 同条件重排和估计量

在每个出生队列内部，以出生州×来源性别、出生季度和年龄 20 对应的公历年划分配对组。继承 R10 公历 7 月 1 日的年龄规则，故每组在同一模型年龄对应同一公历年。固定八字轨迹在原记录上的位置。把紫微斗数、七政四余和西方占星各自的整条 40 年二值轨迹分别在组内均匀重排。每次都保留每个体系在组内每一年龄的高分数、同一条轨迹的年龄相关性及原权重。允许随机保留原配对。单记录组保留原配对，并报告其权重占比和有至少 2、5、10 位候选者的权重占比。季度组至少 95% 的权重须落在可重排的多记录组。

对每个组的每个年龄，从四个高分边际比例精确计算独立配对时“三个或四个达到阈值”的概率。再按组内人数和原权重汇总为重排期望 (E)。令原比例为 (J)，剩余重合为 (R=J-E)。对每个目标报告 (J_t-J_{06})、(E_t-E_{06}) 和 (R_t-R_{06})，单位是百分点。后两项相加严格等于第一项。减少到仅按州、性别、历年匹配，以及细化至出生月，分别重算期望和剩余差值作描述性敏感性。小组更容易在重排中保留部分原配对，月度结果须连同候选者覆盖一同解释。季度主结果及两种敏感性均报告所有队列，包括不支持原动机的结果。

每个队列做 4,999 次独立重排。用同一条件下的第 2.5 和 97.5 百分位报告配对分布范围。检验统计量是原联合比例偏离其配对期望的绝对值，尾部计入同值并使用 `(1 + 尾部次数)/(1 + 重排次数)`。七组检验一起作 Holm 校正，家族水准 0.05。检验针对样本内轨迹可交换的配对假设。原 R10 条件抽样区间单独引用。配对范围针对给定边际和记录的随机分配，分解的跨队列剩余差异按描述量报告。[随机置换检验的依据](https://doi.org/10.1007/s11749-017-0571-1)

匹配固定粗粒度历法结构和州×性别构成。出生季节不是随机分配的，组内仍保留同一出生时点、具体地点、医院排班、四体系规则及更细天文周期所带来的相关。这里的剩余差值是模型结构，现实断运、死亡或 AI 影响需要另行采集独立结局。

## 开跑、复核和收尾

1. GitHub 上核验本登记、配置与代码后，先运行无出生数据的校准。小样本穷举和边界同值核查须通过。两种合成场景各 120 组，其中一类只含共享季度与年龄规律，另一类保留边际并注入期望为 +1 个百分点的同记录重合。每组 799 次重排。无额外重合场景的 5% 检验拒绝次数须 ≤12，注入场景按 0.05/7 阈值检出次数须 ≥96。它们是该生成模型的检查。
2. 在私有 R10 作业目录或从复算归档恢复的同结构目录运行。验证完整输入、权重和轨迹的校验值。所有队列的重排均值须落在解析期望的五个模拟标准误内。保留原报告、附 3 种配对口径和全 7 组结果。
3. 用另一条 R10 阈值核对路径重新生成全部标记，独立按 0/1 模式计数求配对期望，重放全部置换并复核区间、尾次数、七组校正及六组差值。复核复用相同种子和 NumPy。公开汇总、差异和复核回执。登记、固定输入或计算验证失败时，暂停结论发布并保留失败回执。

### 复现

使用 Python 3.12 和 NumPy 2.3.5。参数 <code>REG_SHA</code> 为在 GitHub 读回后核对的 `protocol.json` SHA-256。<code>PRIVATE_R10_JOB</code> 为 R10 作业目录，包含 `aggregation_ready.json`、`profiles/`、`prepared/` 和 `reference/`。

```sh
python rounds/r11/calibrate.py --registration-sha256 "$REG_SHA" --output calibration.json
python rounds/r11/calendar_controls.py --job "$PRIVATE_R10_JOB" --registration-sha256 "$REG_SHA" \
  --calibration calibration.json --output results.json
python rounds/r11/review.py --job "$PRIVATE_R10_JOB" --registration-sha256 "$REG_SHA" \
  --result results.json --output review.json
```

所有新增公开数据以队列为单位汇总。单条出生和评分资料按 R10 原许可保存在私有目录。
