# R21 研究登记 · 《子平真诠》〈论正官〉全章命例

研究问题是当前月令候选和有条件的救应提示，能复述多少原书区分？本轮锁定国家图书馆所藏世界图书馆发行本。正文 PDF 65–67 页、印页 56–58，附例 PDF 98–99 页、印页 89–90。取正文全章全部六个给出四柱的例子，正文与附例逐项读盘。登记前已知见于原书的命例和分类，尚未运行冻结实现与新规则。六例用于核对来源一致性。[国图影印](https://commons.wikimedia.org/wiki/File:NLC416-11jh010455-35296_子平真詮.pdf) · [同章电子校录](https://m.donglishuzhai.net/chapter/3744.html) · [宪章](../../CONSTITUTION.zh.md)

先检查输入四柱均为六十甲子，另用五虎遁、五鼠遁内部校验。异文保留出处。本轮以原书附例中的具体关系为期望，不将书中叙述的人生评价当作可观察结局。对照 R8 已冻结的月令候选、唯一标记与 BZC 正官条文。如 R8 的输出没有能表达的字段，记作未覆盖，不计为错误预测。

限定程序只检查正官出现在月支本气或正官月支藏干已透的情形。它逐条识别以下已知前提。

| 原书关系 | 在本轮检查的结构 |
| --- | --- |
| 财印并透，日干相隔 | 财、印各一透干，分别位于月、时，日干在中间。 |
| 财印相合 | 财、印各一透干，年、月相邻为干合。 |
| 化官为印、透财 | 月支入完整亥卯未，木为该日主的印，另有木印和财透干。 |
| 遇伤佩印 | 月支入完整亥卯未，木阴干为伤官，两个金印在天干可见。 |
| 合煞留官 | 正官藏于月支，无再透，七杀与比劫相邻成干合候选。 |
| 巳丑会金、两印分工 | 导入本篇对巳丑的用例，庚为伤官，透财与一个印相邻干合，另一个火印能克金。 |

前三条不会自动裁决财印强弱或是否成化。巳丑分支仅重建本章特定口径。若有相反的柱位、缺透干、缺三合成员、正官再透、印无剩余或缺巳丑，测试相应提示应消失。不得牺牲反例来满足正例。正文及附例六例预期均能找到本篇所称结构，反例用于检查条件特异性。先公布这六例及判据，再运行两套实现。本轮沿用 R8 队列指标，未使用任何出生数据或现实结局。
