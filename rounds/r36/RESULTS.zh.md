# R36 · 东亚出生时刻与发生地的字段核验

**日本 e-Stat 的受控出生票仍缺出生分钟和实际发生市或具名医院。** 本轮通过官方统计代码 00450011 的现场利用目录下载公开字段字典，覆核了 **1990–2009 年全部 20 个目标年次**，另查 1974、2023、2025 三个对照年次，共 **18 份不同版本**。本轮获取的是字典及相关说明，逐条档案通过单独的受控申请提供。[官方目录](https://www.e-stat.go.jp/microdata/available-data/onsite?governmentStatisticsCode=00450011) · [申请条件](https://www.e-stat.go.jp/microdata/data-use) · [版本、年次与散列](source_catalog.json)

## 日本人口动态调查

| 所需字段 | 从公开字典核到的内容 |
| --- | --- |
| 出生年月日 | 出生年、月、日为三个独立字段，在出生小时字段前各占两字节。 |
| 出生时刻 | 1990–1991 年的小时从第 37 字节开始，1992–2009 年从第 40 字节开始，均为两字节。有效代码为 00–23。各版本另列不详或历史特殊编码。在 18 个字段表的 1,068 项中，出生时间字段仅到小时。 |
| 登记性别 | 性别为同一条出生记录的一字节字段，各年字典均列原始男、女编码。 |
| 实际出生地 | `国内外（生まれたところ）` 只编码日本或日本以外。`場所の種別` 只编码医院、诊疗所、助产所、自宅、其他。2004–2009 年的都道府县及市区町村按申报地、住所地列示。早期版本的部分地理标签仅为分组序号或附地址编码说明，均未见发生市或具名医院字段。 |

2025 版仍使用两位小时编码。厚生劳动省另公布的市区町村标准输出也只列出生年、月、日、上午／下午及小时。较早研究者从 1974–2010 年日本出生票取得实际出生日期和小时，与本轮字典一致。此证据支持判断目前核到的标准受控版本能提供的精度。[标准输出，第 5–6 页](https://www.mhlw.go.jp/content/001500568.pdf) · [原研究 §3.1](https://www.nber.org/system/files/working_papers/w21402/w21402.pdf)

## 复核

第二次从官方端点取回全部 18 份字典，散列与首次取得一致。逐条检查字段编号、固定长字节位置和编码表，结果逐字节重现。第二套程序直接读原生 XML，以不同方式核对全部版本中的日期、小时、性别、发生国家组与场所类型，共 **126 个字段定位及相应编码定义**。这是项目内部的计算复核。[机器可读结果](results.json) · [核对收据](review.json)

从仓库根目录运行。主解析需 Python 3.10 或更新版、`openpyxl==3.1.5` 和 `curl`。源工作簿仅保存于指定下载目录。

```sh
r36_tmp=$(mktemp -d)
python -m rounds.r36.audit_codebooks "$r36_tmp/books" "$r36_tmp/results.json"
cmp rounds/r36/results.json "$r36_tmp/results.json"
python -m rounds.r36.verify_xml "$r36_tmp/books" "$r36_tmp/results.json" "$r36_tmp/review.json"
cmp rounds/r36/review.json "$r36_tmp/review.json"
```

目录中的逐年条目选择常规《出生票》。字典请求使用该条目所列的代码与版本。来源为日本厚生劳动省《人口動態調査》及政府统计综合窗口的现场利用元数据。发布内容为项目根据字段字典制作的核验记录。[e-Stat 使用条款](https://www.e-stat.go.jp/en/terms-of-use)
