# R13 研究登记 · 晚登记档中的墨西哥 1990 年代出生记录

**OBS-R13-MX-1990S-2026-11-27 · 宪章 v1.0。** 早期公开档案的出生钟点缺口阻止了本项目计算 1990 年代的整代来源样本。复读 INEGI 2022–2025 四档实际找到 71,169 条被记为 1990–1999 年出生的晚登记记录。其中 5,408 条通过与 R12 相同的发生地、登记日期、出生时间、性别和唯一历史时区门槛。3,007 条的分钟字段为零，449 条为 00:00。先用这些质量数据确定设计。研究者在登记时只看过 R8–R12 发布值及新来源字段和计数，未计算或查看 R13 评分。[出生时刻审计](sources/mexico_1990s_audit.json) · [宪章](../../CONSTITUTION.zh.md) · [R12 结项](../../R12.md)

## 问题、参照和边界

计算这四档符合既有口径的全部 5,408 条物理来源记录。检验它们是否有完整 20–59 岁四体系轨迹，并描述相对巴西 2006 固定参照的联合高分年度差值。出生年是 1990–1999，登记年是 2022–2025。推断范围仅限所读档案里有可用出生字段的晚登记记录。选入需匹配 2020 普查发生地点的代码与名称，坐标为发生地参考点，时钟是行政记录所填，准确时间无法现场确认。晚登记且资料齐全的人群有明显选择性，资格比例、排除及舍入现象均保留。

四体系和 20–59 岁历年规则复用 R10。至少三套达到固定巴西 2006 参照的各年龄段第 80 百分位时，计为联合高分年龄。所有符合资格的档案行各权重 1。主要量为该受限全量框的共同高分率减固定参照。报告十个出生年及三个预先固定的时钟子集。其口径分别为排除 00:00、只保留分钟非零、只保留整点。没有抽样误差区间适用于这里的全量框，资料选择和时钟近似仍影响解读。记录级重复按档案行保留，并公开汇总核对。

## 时钟扰动、复核和停止标准

以固定种子 `OBS-R13-MX-1990S-2026-11-27` 和档案物理行键的 SHA-256 排序，取最前 200 条。在同一模型年龄窗口分别把出生时刻加入 −120、−30、+30、+120 分钟的假设误差。报告每种情况下同一记录年是否跨过本来阈值，包括联合标记变化率和四体系各自变化率。这是配对压力测试，整点与非整点属于不同实测记录子群。两种敏感性分别回答测量误差和样本选择问题。

查验 GitHub 上的登记和实际输入封存后才评分。要求 5,408 条完整轨迹、216,320 个建模记录年、865,280 个分数和完整 800 条扰动轨迹。原始模型文件和现有参照按校验值锁定。用第二条原始排序精确边界路径检查所有阈值标记及完整轨迹覆盖，再发布队列汇总、来源失败及限制。假设误差的计算不产生新出生记录。模型输出只用于描述命盘结构。

## 复现

按原档名准备四份 INEGI 档案，并验证 R11 审计中的源文件校验值。使用固定的 INEGI 2020 全国普查 ZIP、IANA 2026c、封存的 R10 巴西 2006 参照和 R10 Linux 评分环境。登记版本和私有目录运行参数如下。[R10 运行环境](../r10/recovery/reference/README.md) · [机器可读登记](protocol.json)

```sh
python rounds/r13/older_births.py prepare --job "$PRIVATE_JOB" --archives "$INEGI_ZIPS" \
  --census "$CENSUS_ZIP" --registration-sha256 "$PUBLIC_REGISTRATION_SHA"
python rounds/r13/older_births.py score --job "$PRIVATE_JOB" \
  --registration-sha256 "$PUBLIC_REGISTRATION_SHA" --input-sha256 "$PUBLIC_INPUT_SEAL_SHA"
python rounds/r13/older_births.py analyze --job "$PRIVATE_JOB" --r10-job "$PRIVATE_R10" \
  --registration-sha256 "$PUBLIC_REGISTRATION_SHA" --input-sha256 "$PUBLIC_INPUT_SEAL_SHA"
```
