# Prior historical pilot (R7)

This is a separate, limited historical-outcome pilot. It tested four local candidates, not four complete traditional systems. Its original result and supplemental source sensitivity analysis are both preserved.

The primary AA group had 109 known age endpoints (11 deaths at ages 20–59 and 98 verified survivors to age 60). Only 38 people formed 44 within-stratum case–control pairs. The Western local candidate had unadjusted p=0.03407 and Holm-adjusted p=0.3407; no test passed the prespecified family threshold. All baseline Bazi scores were zero, so that candidate’s discriminative ability was not identifiable.

Individual Astro-Databank records, narratives, outcomes and predictions are omitted under the source’s redistribution restrictions. This directory is an aggregate audit, not a fully offline reproducible copy of the earlier pilot. See the separate current R8 protocol for the outcome-free structural study.
